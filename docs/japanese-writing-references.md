# 日本語文章表現に関する参考資料

この案内は、日本語に関する主張や問いの照合先を選ぶために、既知の資料の所在と適用範囲を示すものである。

資料によって確かめられることは異なる。文法の説明は形式の意味を、表記の指針は対象分野での書き方を、用例は実際の使用を示す。どれか一つを日本語全体の正誤判定器にしない。

## 表現を選ぶ基準

### 文化庁「分かり合うための言語コミュニケーション」

[報告本文](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/wakariau/pdf/r1403493_01.pdf) の「Ⅲ 言語コミュニケーションのための具体的方策」は、正確さ、分かりやすさ、ふさわしさ、敬意と親しさを区別する。「正確さ」には、必要な内容を誤りなく、過不足なく伝えることが含まれる。

四つの要素には対立する場合もあるため、相手と目的に応じて重みを変える。単に丁寧にする、短くするという一律の選択ではない。

### 文化庁「公用文作成の考え方」

[建議と解説](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/93651301_01.pdf) の「基本的な考え方」「Ⅱ 用語の使い方」「Ⅲ 伝わる公用文のために」を参照する。元の内容を損なわないこと、読み手に合う媒体を選ぶことを、文の組み立てと表現の工夫につなげている。

見出し、箇条書き、図表、例、注記の選択にも根拠がある。受身や二重否定の扱い、文長の目安は公用文の伝わりやすさの指針であり、文学や会話一般の文法規則ではない。漢字や送り仮名などの詳細は、同資料が示す該当の告示を使う。

## 語義と用例

国立国語研究所『言葉に関する問答集―言葉の使い分け―』[問1](https://www2.ninjal.ac.jp/past-publications/publication/catalogue/shin_kotoba_series/11_19/pages/12q01/index.html) は、異なる事柄を表す語の違いと、同じ事柄について硬さや丁寧さを選ぶことを区別する。語を言い換えるときは、先に意味が同じかを考える。

辞書の語義と用法は個別語の意味の照合先となる。前後の文脈を伴う用例は、語の組合せや慣用を調べるための資料となる。

- [BCCWJ の概要](https://clrd.ninjal.ac.jp/bccwj/index.html): 対象とする書き言葉の資料構成を知る。
- [少納言](https://shonagon.ninjal.ac.jp/): 文字列から用例を探す。
- [中納言の案内](https://clrd.ninjal.ac.jp/chu-01.html): 形態論情報を使う検索の利用条件を知る。

用例の適用範囲は、意味に加えて文章の種類と年代にも依存する。用例があることは、その場面で使われた証拠であり、すべての文章で適切な証拠ではない。検索で見つからないことも、誤用の証明にはならない。

各資料への接触には、その資料の利用条件と実際の権限が関わる。

### 外来語と専門用語

国立国語研究所「『外来語』言い換え提案」の [利用の手引き](https://www2.ninjal.ac.jp/gairaigo/Teian1_4/tebiki.html) は、文脈に応じて言い換え語を選ぶことと、専門概念を曖昧にするくらいなら原語に説明を添えることを示す。当時の理解度調査を現在の全読者へ当てはめず、一語一訳の置換表として使わない。

[JTF日本語標準スタイルガイド（翻訳用）](https://www.jtf.jp/tips/styleguide) は、実務翻訳の表記をそろえるための資料である。語義や文法一般の正本ではなく、翻訳文の表記方針を決める場面で参照する。

## 表現形式と媒体

- デジタル庁デザインシステムの [見出し](https://design.digital.go.jp/dads/components/heading/) と [箇条書き](https://design.digital.go.jp/dads/components/list/): 節の主題と項目の列挙を区別する。すべての文書に見出しを要求しない。固有の HTML 実装方針は他の媒体へ持ち込まない。
- [W3C WAI の見出しの手引](https://www.w3.org/WAI/tutorials/page-structure/headings/): 見出しが伝える文書構造を扱う。
- [W3C WAI の表の手引](https://www.w3.org/WAI/tutorials/tables/): 行列に論理関係がある場合の表と、見出しとセルの対応を扱う。
- [W3C のリンク目的の解説](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html): リンク文字列または対応する文脈から、行き先の目的を判断できることを扱う。
- [W3C の認知・学習障害に配慮した内容の指針](https://www.w3.org/TR/2021/NOTE-coga-usable-20210429/): 段落、手順、補足などを通じた負担の軽減を扱う。補足的な指針であり、WCAG の適合要件ではない。
- [CommonMark 0.31.2](https://spec.commonmark.org/0.31.2/): Markdown の構文成立条件を調べる。すべての表示環境が同じ拡張や挙動を持つとは限らない。

ウェブ固有の実装を、PDF や Markdown へそのまま移すものではない。対象の形式で表せる範囲で、同じ意味関係を読者に届ける。

これらの指針は形式を選ぶ理由を示すが、このスキルによる日本語の読解時間や誤読率の改善を実測したものではない。
