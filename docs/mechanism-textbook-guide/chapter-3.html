読む順序：第1章 → 第2章 → 第3章 → 第4章

  3. 第3章　説明の設計と執筆（第1〜2章が前提）
  4. 第4章　確認と修正の進め方（第1〜3章が前提）

幅の広い図表は、その枠内を横に送って読める。出典番号は章末の注に対応する。

対象の性質を支える前提と規則を調べても、それをどの順に、どの深さで教えるかはまだ決まらない。1.1 調査・設計・制作の役割で見たように、章の設計は対象理解と読者の情報を受け取り、本文を作るための順序を与える。この章では、前提のつながりから章と節を設計し、読者がたどる推論と表現に分け、本文で使える形にするまでを追う。[5][6]

3.1　章の順序と説明の深さ

まず、対象について組み立てた知識を、読者が学べる順序に直す。何を先に教え、個々の事柄をどこまで説明するかは、対象の前提関係と読者がすでに知っていることの両方から決める。[5]

ある事柄を理解するために、どの考え方や関係が必要かをたどり、その先を読者の既有知識までつなぐ。[5]2.1 読者の到達点と既有知識で見たように、既有知識は名前だけ知っていることと、説明に使う性質まで知っていることを区別して記録する。[2]したがって、名前が記録されているだけなら、その性質を前提にして話を飛ばすことはできない。必要な考え方を教える位置まで含めて順序を組む。[5]

章どうしの順序は、章の前提から決める。1.2 学ぶ順序と表現の分担で述べたように、ある章が別の章を前提にするとは、結果を導くときに、別の章で教えた事柄の理解を使うことである。そのため、使われる事柄を教える章を、使う章より前に置く。[5]

2.2 前提と規則の組み立てで見た対応物は、読者がすでに知り、同じ役割を果たすもので、違いを説明すれば新しい事柄を理解する足場になる。[3]

例えば章Aがある規則を教え、章Bがその規則を使って結果を導くとする。章CはAとBを前提にせず、AとBからも前提にされない。図3では、AからBへ向かう依存と、独立したCを見てほしい。[5]

この入力では、規則を知ってからその規則で導くので、AをBより先に置く。一方、CとA、CとBの間にはその制約がない。独立した章どうしについては、それぞれが教える事柄のうち、対応物がある事柄の割合を比べ、割合の大きい章を先にする。図のCの位置だけから、Cが必ず最初や最後に来るとは決まらない。[5]

対応物がある事柄では、その既知のものを示し、違いを説明する。独立した節を立てて最初から説明し直すのではなく、既知のまとまりを使って新しい関係へ進む。対応物がなければ、独立した節を立て、必要になる場面と前提を示して仕組みを教える。順序を選ぶときと説明の深さを選ぶときに、同じ読者情報を別の判断へ使っている。[5]

前提を並べるだけでは、章の話はまだできない。各章で読者が何を知るところから始め、何を見て考え、どの理解に至るかを組み立てる。編集責任者は章ごとに前提にする章と役割を決め、到達点への寄与に応じて重みを定める。資料が豊富にある部分を長くするのではなく、読者が目指す理解に必要な部分へ紙幅と詳しさを配る。その判断は作業記録に残し、変えたときには記録も直す。[5]

3.2　節の問いと導出の段

章の順序を決めたら、各節の説明が実際に結果まで届くかを設計する。ここでは、読者が何を考える節なのかと、その推論に必要な前提をどう記録し、確かめられるようにするかを見る。[6]

1.1 調査・設計・制作の役割で見たように、章の設計は何をどの順にどう教えるかの記録である。その記録の節ごとの部分には、節の問い、必要になる場面、そこで教える事柄と推論を書く。1.2 学ぶ順序と表現の分担で見た節の問いは、その節で説明することであり、導出の段は、結果へ至る関係を一つずつ当てはめる記録である。節の問いがあることで、記録する事柄や後で選ぶ表現を、何の理解のために置くのか結び付けられる。[6]

導出の各段には、当てはめる定義、規則、式、事実を一つだけ置く。二つの関係が必要なら二段に分ける。さらに、その段の前提が読者の既有知識なのか本で教える事柄なのかを添え、後者なら教える節を示す。前提や当てはめる関係が対象についての事実なら、資料の箇所や照合を終えた模型の出力など、事実を支える出典も添える。これによって、どの関係で進んだかと、その関係や前提をどこから得るかを別々にたどれる。[6]

設計時には、到達点に書いた推論ごとに、本文で答えを述べない「確認用の例」も選ぶ。これは書き手と確認者が、本の説明から結果と理由を導けるかを確かめるための例である。例ごとに、どの節まで読んだ読者が導けるはずかを添え、そこまでに教えたことと既有知識だけを前提として、導出の段を書く。本文自体の推論なら、その推論を述べる箇所より前に教えたことと既有知識が前提になる。確認用の例は作業記録に置き、演習に使う場合を除いて本文には載せない。[6]

導出を分ける働きを、このスキルの規則を当てはめる例で見る。ある応用の説明に、それまで教えていない性質が必要だと分かったとする。表の各行は、入力から次の判断へ進むときに使う関係を一つずつ示している。[6][8]

未説明の前提が見つかったときの導出の段 [6][8]
段使う関係または入力その段で分かること
1既習事項の応用には未説明の知識を使わない。[8]応用の前提には、すでに説明した知識が必要である。
2必要な性質は、それまで教えていないという例の入力。その性質は、現在の応用箇所では未説明である。
3段1の規則を段2に当てはめる。[8]その性質を現在の応用の前提には使えない。
4必要な前提が見つかれば、設計と説明に戻って教える節を直す。[8]その性質を先に教えるように直す。

段2は例の入力であり、スキルが特定の対象について観察した事実ではない。これに対して段1と段4はスキルの規則である。両者を区別すると、どの入力にどの規則を当てはめて「先に教える」と決めたのかが分かる。実際の章で使う性質なら、それが既有知識の記録にあるか、どの節で教えるかを調べる。[6][8]

対象についての事実に出典を添えられない場合、その事実を導出の段には使わない。必要なら対象の調査へ戻って確かめるか、根拠のある事実から対象についての結論を導けるよう、推論を組み直す。それでも到達点の一部が導けなければ、未達の範囲と理由を記録し依頼者に報告する。到達点を小さく書き換えて完了したことにはしない。[6]

主張や式の成立条件と例外も、あらゆるものを節の設計へ集めるのではない。その主張や式が現れる導出のいずれかの段で、前提か当てはめる関係にしているものを記録する。後の本文はこの節の構成から書くため、条件と推論の対応も設計の時点で追える。[6][10]

3.3　表現の分担と図の計画

同じ節でも、理由を順にたどることと、複数の項目を比べることでは、読者が行う操作が違う。節の問いと導出が決まったら、示す関係と読者にしてほしい操作を取り出し、それぞれに合う表現を選ぶ。[13]

2.2 前提と規則の組み立てで述べた理解の型は、構造や振る舞いのように、読者が理解するときに頭の中に組み立てるものの種類である。[3]表現を決めるときはこの型も使い、どんな関係をたどるかを考える。例えば理由から結論への筋道なら文章にし、共通の観点で複数の項目を比べるなら表にする。理由の説明と比較が両方必要な節では、文章と表に仕事を分ける。[13]

読者が行う操作と、表現に持たせる仕事 [13]
示す関係と読者の操作選ぶ表現持たせる仕事
前提や理由から結論へ進む文章条件、理由、結論を文で結ぶ。
操作を指定された順に実行する番号付き手順各操作とその順序を示す。
同格の項目を個別に拾う箇条書き各項目を独立に拾えるようにする。
複数の項目を共通の観点で比べる表項目と観点を行と列にそろえる。
一か所にそろっていない接続や、分岐・合流の経路をたどる図要素と接続、向きや分岐の条件を示す。
定義した量の関係を当てはめ、計算・変形する式と文章関係と記号、操作の意味を示す。
条件を変えた結果の変化を確かめる操作して読む図条件を変え、結果の変化を見せる。操作できない媒体などでは状態を並べる。

これは表現を一節一種類に決める表ではない。例えば比較の表に加え、その比較からどのような理由で結論へ進むかは文章に担わせる。文章も「図を選ばなかった残り」ではなく、理由を順に結ぶという仕事を持つ。どの事柄や関係をどの表現で示すか、文章を選んだものも含めて章の設計に記録する。[13]

図に割り当てた仕事については、描く前に図の計画を作る。図4は、関係と読む操作の抽出から分担が決まり、図の側で形を決めた後、全章の設計を確認して描画へ進む経路を示す。図にしない側の文章や表なども、分担として記録される。[13][14][6]

図の計画では、まず読者の頭の中に作らせたいもののうち、その図が受け持つものを決め、それが成り立つ空間を選ぶ。次に、その空間で答えられる問いを一つ決め、答えを出す。例えば接続をたどる仕事なら、図3のように章と章の依存を描く空間で、どの章を先にするかを問える。図を操作して読むか、見るだけで読むかを決めたうえで、問いへの答えを形から読み取れるように形を選ぶ。[14]

2.3 模型と形の仮定で見たように、模型は入力から結果を計算するもので、形の仮定は対象の接続や作用などについての仮定である。模型を作った対象では、その出力から図の形と数値を作り、図と添える数値にも同じ出力を使う。仮の入力で作る図でも、その入力を模型に与え、図の説明に入力の値を示す。仮の入力からの結果は実測値ではない。模型を作らない構造図でも、描く部分と関係を形の仮定に合わせる。[14][15]

図の問いと答え、空間、読み方、形、置く節を記録し、図を含む全章の設計の確認を受けてから描く。図は説明する文のすぐ隣に置く。図がどの関係を受け持ち、文章が何を説明するかを、読者が行き来しながら探さずに結び付けられるようにするためである。[6][14][16]

3.4　章の中で前提をそろえる

章と節を設計しても、読者が離れた章の内容を覚えているとは決められない。そこでスキルは、章を読み始めたところから、そこで使う事柄をどう説明するかを定める。本文の冒頭、用語、図と出典も、この道筋に沿って置く。[1][7][10]

ここでの章は読者が読み始める単位であり、節は章の直下の見出しで区切るまとまりである。章を読み始める読者は、その章が前提にする章と、さらにそれらが前提にする章を読み終え、章の中では先頭から順に読むものとする。この読み方のもとで、章の中で使う語や性質、推論が前提にする事実は、次の四つのいずれかに当てる。[1]

章の中で使う事柄の四つの扱い [1]
事柄の位置付け使うときの扱い
その章の中で教える使う箇所より前に説明する。
読者の既有知識にある今の説明に使う性質まで記録にあることを要する。名前だけの記録なら、名前で指すことに使う。
前提にする章で教えた名前で指すだけなら同じ名前を使う。推論の前提にするなら、必要な性質を一文で言い直し、教えた節の名前を示す。
まだ教えていない、または前提にしない章で教える使う箇所で、そこで知っていれば足りることを述べ、教える節を示す。ただし既習から結果を導く過程と演習では推論の前提にしない。

例えば1.2 学ぶ順序と表現の分担で教えた章の前提は、別の章で教えた理解を結果の導出に使う関係である。3.1ではこの性質を言い直してから、使われる事柄を教える章を先に置くと説明した。単に「章の前提」という名前を指す場合とは違い、その性質を理由として使っているからである。前提章で教えた図の部分なら、一文で言い直す代わりに図を再び示してもよい。[1][5]

章と節の始まりにも、読者が今から何を学ぶかを示す文章を置く。章の最初の段落はその章で説明することと、それが必要になる場面を示す。場面は、前提章の内容か読者の既有知識から言い直す。節の最初の段落も、その節で説明することを示す。どちらも図や表、箇条書きより前に置く。[1]

新しい用語は、必要になる場所で意味を説明し、その後も同じ意味で使う。名前には、その分野の日本語の文書で使われる表記を用い、根拠の資料で使う名前が異なれば導入時にそれも示す。日本語の表記がない場合は資料の名前をそのまま使う。意味は平易に説明し、その事柄が何を表し、他の知識とどうつながるかを示す。また、読者の誤解を取り上げるのは、本人の発言や記録、途中の評価などでその誤解が観測された場合に限る。[7]

1.5 本文と作業記録の役割で見たように、本文は対象について理解するための説明であり、参照資料は必要なときに引く情報を置く。したがって推論に不可欠な前提は本文の道筋に残し、網羅的な一覧や検証記録は参照資料へ分ける。[10]

本文の主張には、根拠の具体的な箇所を指す短い参照番号を付ける。同じ箇所が段落全体を支えるなら段落末にまとめ、根拠箇所が変わる文では番号を分ける。図や表にも説明文の末尾に付け、内部の部分ごとに根拠箇所が異なればその部分に付ける。資料が支える前提と、そこから導いた結論を区別することで、読者は何が根拠で、どこからが推論かをたどれる。[10]

3.5　具体例と演習

設計した説明は、規則を述べるだけでなく、それを使って結果が得られる過程を示すことでつながる。最後に、既習の知識から導く部分と新しい知識を教える部分の境目、および読者が自分で試す演習の役割を整理する。[8]

3.1の章A・B・Cの例に戻ろう。Aが規則を教え、Bがそれで結果を導くという入力に対し、事柄を教える章をそれを前提にする章より先に置く規則を当てはめると、AがBより先になる。Cについては、A・Bとの依存がないという入力から、依存による順序の制約は生じない。そこで、互いに依存しない章には対応物のある事柄の割合で順序を決めるという別の規則を当てはめる。どの章の割合が大きいかによってCの位置を選ぶことになる。[5]

この例では、入力と、すでに3.1で説明した規則を分けている。結果を導くために必要な性質が既習でなければ、応用箇所でそのまま使わず、元のスキルの手順3「読者が理解を獲得する順序を設計する」と手順4「新しい知識の必要性と意味を伝える」へ戻り、教える節と説明を直す。新しい知識を教える段階に進むときも、既習事項だけで導けたところと、新しく教えるところの境目を示す。こうして読者は、何を自分で導け、何を新たに学ぶ必要があるかを追える。[8]

一つの例だけでは、条件を変えても結果が同じように見える場合がある。そのときは条件を変えた例や比較を示し、共通する関係と変わる結果を説明する。先ほどの例なら、AをBより先に置く依存は保ったまま、独立する章の対応物の割合を変えて、独立な章どうしの順序がどの情報で決まるかを比べられる。[5][8]

作業記録の確認用の例と、読者向けの演習は役割が異なる。3.2で見たように、確認用の例は本の説明から到達点の推論を導けるかを、書き手と確認者が確かめるために作る。[6]演習は、読者が読み終えた後に自分で行うことを到達点が求める場合に、その行為を試すために置く。到達点が複数の行為を求めるなら、それぞれに演習を置き、演習の形も到達点と同じ形にする。本文の答えを探すだけでは済まない課題にし、解答を付けるなら筋道を示しつつ、読者が先に考えられる位置に置く。[8]

到達点が用語や結果を思い出すこと、あるいは仕組みを説明することだけなら、スキルは演習を置かない。本文の内容が資料や設計に合っているかを確かめることと、読者が実際にどのように学べたかを確かめることも別である。確認と修正の進め方は、次の章で扱う。[8][9]
