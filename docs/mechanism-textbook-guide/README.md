# mechanism-textbook の手順を読む

`index.html` をブラウザで開き、第1章から第4章へ読む。フォルダごとコピーして利用でき、ローカルサーバーは不要。
**図の描画にはCDNへの接続が必要。出典の閲覧にもインターネット接続が必要。** GitHub上では、このREADMEから章立てと出典を参照できる。HTMLを読む場合はファイルをダウンロードしてブラウザで開く。

- [index.html](index.html)：教科書を作る仕事の全体像
- [chapter-2.html](chapter-2.html)：対象理解と読者の出発点
- [chapter-3.html](chapter-3.html)：説明の設計と執筆
- [chapter-4.html](chapter-4.html)：確認と修正の進め方（演習・折りたたみ解答を含む）

Mermaid は [jsDelivr CDN](https://cdn.jsdelivr.net/npm/mermaid@10.9.3/dist/mermaid.min.js) から **10.9.3** を読み込む。ライブラリ本体やスキルの複製は同梱しない。
