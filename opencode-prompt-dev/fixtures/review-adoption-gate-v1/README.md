# 監査後採否ゲートの派生フィクスチャ

## 目的

独立監査が `pass` でも、監査対象と採用対象の同一性、完成修正候補作成後の不変性、基準版の不変性のいずれかを確認できない場合に、手続き全体が一意に `fail` となることを確認する。

## 由来

`prompt-flow-consistency-v1` の F15 で、独立監査単体の `pass` と採否ゲート失敗後の手続き全体結果の関係が実行者間で分かれた。G1〜G3は、その失敗族だけから各採否条件を独立させた派生シナリオである。

## 実行

新規実行者へ `scenarios.md` だけを渡し、各シナリオの監査結果、手続き全体結果、採否、同じ手続き内で許される次の操作を返させる。採点者は `scoring.md` で判定する。実行者へ採点基準を渡してはならない。
