# 最終確認シナリオ

## G1 採用対象の識別子欠落

独立監査は完成修正候補Aへ `pass` を返した。監査対象には内容識別子があるが、採用対象には版も内容識別子もなく、同一性を確認できない。

## G2 候補不変性の証拠欠落

独立監査は完成修正候補Bへ `pass` を返した。監査時と採用時の内容識別子は一致するが、候補作成後に内容が変更されていないことを確認できない。

## G3 基準版不変性の証拠欠落

独立監査は完成修正候補Cへ `pass` を返した。候補の同一性と候補作成後の不変性は確認できるが、採用時の基準版を識別できず、監査時から基準版が変わっていないことを確認できない。
