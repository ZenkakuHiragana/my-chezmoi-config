# 検証用集合の採点基準

各項目を意味で判定する。項目の語句を出力へ逐語的に書く必要はない。

## A1

- `[critical] A1-1`: BとCを直接読んで得た実差分から、親提示差分との不一致または認可されていないYを確認する。
- `[critical] A1-2`: 監査結果を不合格とする。
- `[critical] A1-3`: Cを採用せず、Rを合格にしない。
- `[critical] A1-4`: 同じ手続き内で候補の修正・差替え・再監査へ進まない。
- `[critical] A1-5`: 固定指摘と差分照合の外から新しい問題を追加しない。

## A2

- `[critical] A2-1`: 親の成功記録ではなく、監査者自身がMで観測した結果を修正結果の根拠にする。
- `[critical] A2-2`: 監査結果を不合格とする。
- `[critical] A2-3`: Cを採用せず、Rを合格にしない。
- `[critical] A2-4`: 同じ手続き内で候補の修正・差替え・再監査へ進まない。
- `[critical] A2-5`: 固定指摘Fの外から新しい問題を追加しない。

## A3

- `[critical] A3-1`: 監査者自身のMによる再現を、親の `rejected` 裁定との不一致として扱う。
- `[critical] A3-2`: 裁定監査の結果を不合格とする。
- `[critical] A3-3`: Rを合格にしない。
- `[critical] A3-4`: 同じ手続き内で修正候補作成や再監査へ進まない。
- `[critical] A3-5`: 固定指摘Fの外から新しい問題を追加しない。

## A4

- `[critical] A4-1`: 親の成功記録をMの実行に代用せず、必要な独立確認を実行できないと判断する。
- `[critical] A4-2`: 監査結果を判定不能とする。
- `[critical] A4-3`: Cを採用せず、Rを合格にしない。
- `[critical] A4-4`: 同じ手続き内で入力差替え、候補変更、再監査へ進まない。
- `[critical] A4-5`: 固定指摘と確認方法Mの外から新しい問題を追加しない。

## A5

- `[critical] A5-1`: 親の確認失敗により、Cを完成候補として独立監査へ送る前提が成立しないと判断する。
- `[critical] A5-2`: 手続き結果を不合格とする。
- `[critical] A5-3`: Cを採用せず、元のレビュー対象を合格にしない。
- `[critical] A5-4`: 同じ手続き内で候補の修正・再作成・監査起動へ進まない。
- `[critical] A5-5`: 固定された修正後確認の外から新しい問題を追加しない。
