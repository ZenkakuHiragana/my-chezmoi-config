# 採点者作業票

- 作業分類: 限定
- 実行モード: 読み取り専用
- 目的: 固定済みの実行者出力をcriterion単位で採点する
- 範囲: 供給されたシナリオ、実行者出力、対応criterionだけ
- 入力: シナリオ本文、不透明な `run ID`、実行者出力、criterion
- 読取可能: 供給された入力だけ
- 編集可能: なし
- 制約: 逐語一致ではなく、判断、採否、禁止操作の意味で判定する。各判定に出力中の根拠を付ける
- 禁止事項: 腕を推測しない。他の採点者結果、他出力、較正資料、ワークスペースを読まない。criterionを追加、削除、結合しない
- 必要な根拠: criterionごとに、合致または不一致を示す実行者出力の引用
- 出力形式: JSON配列。各要素は `criterion_id`、`judgment: pass | partial | fail`、`evidence`、`missing`、`confidence: high | medium | low`
- 検証のヒント: 同義表現を許し、明示された処分と実際に許可した次の操作を合わせて読む
- 停止条件: 全criterionを1回ずつ採点した時点。根拠が足りなければ `partial` と不足を返す
- 統合方法: 親は採点を変更せず、別採点者結果と機械的に照合する
