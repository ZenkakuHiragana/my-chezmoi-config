# 独立監査の盲検比較フィクスチャ

このパックは、独立監査の基準版と完成修正候補を比較し、直接確認、裁定確認、候補処分、停止性を意味単位で評価する。

## 構成

- `validation-scenarios.md`: 既知の失敗を再現する検証用集合。
- `validation-scoring.md`: 検証用集合の採点基準。
- `holdout-scenarios.md`: 候補設計に使わない最終確認集合。
- `holdout-scoring.md`: 最終確認集合の採点基準。
- `executor-packet.md`: 1シナリオを実行者へ渡す作業票。
- `grader-packet.md`: 固定済み出力を採点者へ渡す作業票。
- `calibration.md`: 採点基準を較正する良例と悪例。

## 配送境界

実行者には、片腕の適用規則、1シナリオ、`executor-packet.md` の指示だけを渡す。ファイル名、パック名、採点基準、試験意図、腕の意味、他のシナリオ、他の出力を渡さない。

採点者には、シナリオ本文、不透明な実行ID、実行者出力、対応する採点基準、`grader-packet.md` の指示だけを渡す。腕の意味、他の採点者結果、較正資料を渡さない。

## 判定単位

各採点項目は `[critical]` であり、1つの判断、採否、禁止操作のいずれかを扱う。同義の表現は同じ結果として認める。見出し、項目名、固定句の逐語一致は要求しない。

## 固定

実行開始前に、このパック、対象規則、実行設定、集計規則の内容識別子を固定する。固定後は、生出力、採点結果、実行識別子、時刻、集計結果だけを追記できる。
