# 最終確認集合の採点基準

各項目を意味で判定する。項目の語句を出力へ逐語的に書く必要はない。

## H1

- `[critical] H1-1`: BとCから取得した実差分から、親提示差分にだけあるZとの不一致を確認する。
- `[critical] H1-2`: 監査結果を不合格とする。
- `[critical] H1-3`: Cを採用せず、Rを合格にしない。
- `[critical] H1-4`: 同じ手続き内で差分書換え、候補変更、再監査へ進まない。
- `[critical] H1-5`: 固定指摘と差分照合の外から新しい問題を追加しない。

## H2

- `[critical] H2-1`: F1とF2へ同じ確認方法を個別に適用した結果を裁定確認に使う。
- `[critical] H2-2`: F2の再現を親裁定との不一致として扱い、裁定監査の結果を不合格とする。
- `[critical] H2-3`: Rを合格にしない。
- `[critical] H2-4`: 同じ手続き内で修正候補作成や再監査へ進まない。
- `[critical] H2-5`: 固定されたF1とF2の外から新しい問題を追加しない。

## H3

- `[critical] H3-1`: Rを直接読めないことを、必要な独立確認の不足として扱い、親の詳細記録で代用しない。
- `[critical] H3-2`: 監査結果を判定不能とする。
- `[critical] H3-3`: Cを採用せず、Rを合格にしない。
- `[critical] H3-4`: 同じ手続き内で参照差替え、候補変更、再監査へ進まない。
- `[critical] H3-5`: 固定指摘とRの確認の外から新しい問題を追加しない。

## H4

- `[critical] H4-1`: R、B、Cの直接読取、実差分、裁定、修正結果を監査者自身の観測で確認する。
- `[critical] H4-2`: 監査結果を合格とする。
- `[critical] H4-3`: 監査したCと同じ候補を採用対象にし、Rを未修正のまま合格にしない。
- `[critical] H4-4`: 同じ手続き内で候補の再編集・差替え・再監査へ進まない。
- `[critical] H4-5`: 固定指摘Fと修正契約の外から新しい問題を追加しない。
