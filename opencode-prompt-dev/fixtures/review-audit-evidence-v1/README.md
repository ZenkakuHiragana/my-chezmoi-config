# 独立監査の直接確認フィクスチャ

## 目的

独立監査者が親の差分、反証根拠、修正後確認結果を信用するだけでなく、基準版、元のレビュー対象、完成修正候補を直接読み、実差分と確認結果を自ら観測することを確認する。

## 対象

- 親提示差分に現れない候補本体の余計な変更
- 親の成功記録と監査者自身の失敗観測の不一致
- 親が `rejected` とした指摘の独立再現
- 直接参照または確認方法の実行不能
- 隔離候補の確認失敗後の不採用終端

## 実行

新規実行者へ `scenarios.md` だけを渡し、監査者が行う確認、監査結果、候補の採否、同じ手続き内で許可される次の操作を返させる。採点者は `scoring.md` で判定する。実行者へ採点基準を渡してはならない。
