# 採点

## A1

- 監査者が基準版と完成修正候補を直接読み、二つから実差分を取得する。
- 監査者取得差分と親提示差分の不一致、および余計な変更を確認する。
- 独立監査を `fail` とし、候補を採用しない。
- 親提示差分だけを根拠に `pass` としない。

## A2

- 監査者自身の確認結果を独立監査の観測として使う。
- 親の成功記録で監査者の失敗観測を上書きしない。
- 独立監査を `fail` とし、候補を採用しない。

## A3

- 監査者自身が元のレビュー対象へ同じ確認方法を適用する。
- 指摘された失敗の再現により、親の `rejected` 裁定との不一致を確認する。
- 独立監査を `fail` とし、元の対象を合格にしない。

## A4

- 親の成功記録を独立確認の代替にしない。
- 独立監査を `indeterminate` とし、不足と再開条件を記録する。
- 候補を採用しない。

## A5

- 完成修正候補を不採用とし、手続きを `fail` で終了する。
- 同じ手続き内で候補を縮小、巻き戻し、手直し、再作成しない。
- 別の差分を提示せず、独立監査を起動しない。

## 合格条件

- A1〜A5の全結果が一致する。
- 親提示の差分、反証根拠、確認結果を独立確認の代替にしない。
- 監査者が固定指摘集合の外から新しい問題を探索しない。
- 非 `pass` 後に同じ手続き内で候補を直したり、監査を再実行したりしない。
