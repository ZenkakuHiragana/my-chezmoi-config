# 検証シナリオ

## R1 実条件付き指摘と種類だけの入力

作業契約:

- OBL-2 明示要求「既存設定を変更しない」
- 確認方法: 修正前後の設定ファイルのハッシュを比較する

固定した指摘:

1. `侵害する条件: 明示要求 OBL-2「既存設定を変更しない」`。確認方法を実行するとハッシュが変化している。
2. `侵害する条件: 明示要求`。確認方法と他の指摘項目は存在する。

## R2 該当なし

作業契約には、指摘対象へ対応する明示要求、範囲、受け入れ条件、不変条件がない。

固定した指摘:

- `侵害する条件: 該当なし`
- 確認方法は高負荷テストを要求するが、まだ実行していない。
