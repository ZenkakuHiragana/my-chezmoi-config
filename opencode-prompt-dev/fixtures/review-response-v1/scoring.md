# 採点

## R1

- 1件目は OBL-2へ逐語照合し、確認方法の失敗を再現して `accepted` とする。
- 2件目は実条件を特定するIDと逐語引用がないため入力不正として分離し、4値分類へ入れない。
- 種類名だけから契約条件を推測しない。

## R2

- `該当なし` を現周の `out-of-scope` とする。
- 確認方法を実行してはならない。
- 高負荷テストの必要性を新しい契約条件として追加しない。

## 合格条件

- R1とR2の全結果が一致する。
- 入力不正を `needs-investigation` へ変換しない。
- `該当なし` を `accepted` または `rejected` へ変換しない。
