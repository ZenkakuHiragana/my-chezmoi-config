# プロンプト制御フロー接続フィクスチャ

## 目的

`work_class` ごとの準備完了経路、要件レビュー経路、実装入口と、`broad-or-unclear` レビューの二段階手続きが一意に決まることを確認する。

## 対象

- `tiny-local` の軽量な準備完了経路
- `bounded` の直接要件レビュー経路
- `broad-or-unclear` の初回レビュー、親裁定、完成修正候補、独立監査、採否
- 未定義の代替契約による実装入口の拒否
- 親が所有する手続きと子へ割り当てる初回検査・独立監査の分離
- 固定済み要件契約から派生した作業契約のレビュー
- 指摘ゼロ、`accepted` 0件、`needs-investigation`、`判定不能` の各終了経路
- 完成修正候補の範囲、同一性、監査結果
- 手続き終了後の改版と、終了した手続き結果の効力範囲
- コードレビューを含む全レビュー種別への共通手続き

## 実行

`scenarios.md` の各シナリオを新規実行者へ渡し、開始可能な次段階、必要な成果物、使うレビュー経路、停止理由を返させる。採点者は `scoring.md` で判定する。実行者へ採点基準を渡してはならない。
