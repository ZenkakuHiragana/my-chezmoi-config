# プロンプト制御フロー接続フィクスチャ

## 目的

`work_class` ごとの準備完了経路、要件レビュー経路、実装入口と、レビュー周回の責任境界が一意に決まることを確認する。

## 対象

- `tiny-local` の軽量な準備完了経路
- `bounded` の直接要件レビュー経路
- `broad-or-unclear` のレビュー周回経路
- 未定義の代替契約による実装入口の拒否
- 親が所有するレビュー周回と子へ割り当てる検査単位の分離
- 固定済み要件契約から派生した作業契約のレビュー
- 要件契約候補レビューの必須単位と入力不正
- 初回レビュー結果を保持した4値分類後の終端

## 実行

`scenarios.md` の各シナリオを新規実行者へ渡し、実行者には開始可能な次段階、必要な成果物、使うレビュー経路、停止理由を返させる。採点者は `scoring.md` で判定する。実行者へ採点基準を渡してはならない。
