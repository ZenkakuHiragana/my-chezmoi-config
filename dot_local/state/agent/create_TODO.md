# やることリスト

最初の `## ` の見出しより前（この説明を含む）は、説明とメモの場所で、やることとしては読まない。

やること1つは、`## ` の見出しから、次の `## ` かファイルの終わりまで。次の形で書く。

    ## 見出し（一覧に出る1行）
    <!-- 2026-11-15 会話の ID -->

    何の話で、なぜやるのか。元の会話を開かなくても思い出せる程度の数行。経緯や決めたことの記録は書かない。

    - サブ目標（あれば、1行に1つ）

- 日付と会話 ID の行はエージェントが足すときに書く。会話 ID は Pi なら `$PI_SESSION_ID` の値を書く。人が足すときは見出しだけでもよい。
- 状態の欄は作らない。終わったことは、サブ目標ならその行を、やることなら見出しからのまとまりを消して表す。
- 新しいやることは末尾に足す。
