# 設計判断の質問

相互に影響する設計判断を、ユーザーが答えられる短い質問へ分ける。質問によって未確認の事実を推測したり、設計案を勝手に確定したりしない。

## 手順

1. 利用できる資料、既存実装、公開情報から確認できる事実を先に確認する。判断に必要な資料へ到達できない、または事実を確定できない場合は、推測せず不足する資料、確認方法、その影響をユーザーへ返して質問作成を止める。
2. 本当にユーザーが決める必要のある選択だけを質問にする。
3. 一回に最大5問とする。
4. 各質問に、推奨する回答と、その回答が影響する設計上の理由を添える。推奨をユーザーの承認として扱わない。
5. 判断が確定し、設計または実装に必要な情報が揃ったら止める。

## 返答内容

返答には、確定した判断、残る未解決の質問、各判断が変える範囲、次に必要な確認、判断に使った確認済み事実と根拠、未確認の制限を含める。質問を増やすために新しい前提や選択肢を作ってはならない。
