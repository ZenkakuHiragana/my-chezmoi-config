# 公開情報源の選択と到達経路

公開情報を調べるとき、必要な情報に応じた最初の根拠と一次資料へ到達する経路を選ぶ。

## 必要な情報ごとの既定根拠

| 必要な情報   | 最初に見る根拠               | 補助根拠                |
| ------------ | ---------------------------- | ----------------------- |
| 構文 / 設定  | 公式文書 / 仕様              | 提供元文書 / 上流コード |
| 版の利用可否 | リリースノート / 版付き文書  | 課題 / 上流コード       |
| 既知の不具合 | 課題管理 / 勧告              | 変更履歴                |
| 実行時挙動   | 上流コード / テスト / 文書   | 公式文書 / 課題         |
| 理由         | 課題 / プルリクエスト / 議論 | 変更履歴 / ブログ       |
| 標準の意味   | 仕様 / RFC                   | 提供元文書              |

所有先が判定対象を定める場合は、補助根拠だけで所有先の判断を置き換えてはならない。
最初の根拠で判定できないときは、補助根拠へ移った理由を記録する。

## 到達経路

1. 既知の権威ある URL があるときは、検索を経ずに直接取得する。
2. ないときは、利用可能な公開検索手段で候補を探す。
3. 検索結果は資料の発見に使い、判断には取得した資料そのものを使う。
