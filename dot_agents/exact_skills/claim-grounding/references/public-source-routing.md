# 公開情報源の選択と到達経路

## 役割

公開情報を調べるとき、必要な情報に応じた最初の根拠と、一次資料へ到達する経路を選ぶ。検索語の機密保護、取得記録、引用、不在の扱いは共通の公開根拠手続きに従う。

## 必要な情報ごとの既定根拠

| 必要な情報 | 最初に見る根拠 | 補助根拠 |
| --- | --- | --- |
| 構文 / 設定 | 公式文書 / 仕様 | 提供元文書 / 上流コード |
| 版の利用可否 | リリースノート / 版付き文書 | 課題 / 上流コード |
| 既知の不具合 | 課題管理 / 勧告 | 変更履歴 |
| 実行時挙動 | 上流コード / テスト / 文書 | 公式文書 / 課題 |
| 理由 | 課題 / プルリクエスト / 議論 | 変更履歴 / ブログ |
| 標準の意味 | 仕様 / RFC | 提供元文書 |

所有先が判定対象を定める場合は、補助根拠だけで所有先の判断を置き換えてはならない。最初の根拠で判定できないときは、補助根拠へ移った理由を記録する。

## 到達経路

1. 既知の権威あるURLがあるときは、検索を経ずに直接取得する。
2. 直接取得するURLがない、または取得できないときは、利用可能な公開検索手段で候補を探す。検索手段が利用できない場合、一般情報はDuckDuckGoの検索ページ、公開コードや公開課題はGitHubの検索ページを代替経路として使う。
3. 検索結果ページは発見にだけ使い、採用する根拠ページを別に取得する。
4. 候補ページのURL、検索手段、検索語、取得操作、版または更新情報を記録する。
5. 根拠が弱いときは、ほぼ同じ検索語を繰り返してはならない。意味を保った検索語の形を変え、変形の上限を接触前に定めて記録する。
6. 一次資料が見つからないときは、その事実を推測と分け、取得できた補助根拠と残る制限を返す。

## 停止

次のいずれかで公開探索を停止する。

- 判定に必要な一次資料または、一次資料が取得できない場合に採用する補助根拠を取得し、引用と位置を記録した。
- 宣言した検索語の変形上限へ到達した。
- 利用可能な到達経路を試し、追加の経路が宣言されていない。
- 取得経路へ到達できず、再開条件を記録した。

検索結果の空集合、検索上限への到達、アクセス不能だけでは、概念全体または公開資料全体の不在を認可してはならない。根拠を取得できなかった範囲と停止理由を記録し、`未決` とする。
