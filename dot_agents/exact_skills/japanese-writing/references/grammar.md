# 文法と意味

伝えたい内容から形式を選ぶための資料である。文法的に成立すること、意図した意味になること、場面にふさわしいことは別の判断である。以下の例は使い分けを示すために作成したものであり、資料からの引用ではない。

## 述語から文を組み立てる

助詞は、名詞が述語に対して担う役割を示す。

> 担当者が利用者に結果をメールで知らせる。

この文では「担当者」が知らせる主体、「利用者」が相手、「結果」が内容、「メール」が手段である。述語が変われば、名詞との結び付きも変わる。「資料に基づく」と「資料を基にする」の助詞は、名詞が同じだからといって統一できない。

文の主題と動作主は一致するとは限らない。「この資料は担当者が更新する」では、話題にしているのは資料であり、更新する主体は担当者である。「は」が付いた語を必ず動作主として読むと、この違いを失う。

後ろの語に合う活用形を使う。「静かな部屋」では名詞を、「静かに話す」では動作を修飾する。長い名詞句も、助詞を使って関係を表せる。「新規顧客対応手順変更案」が新規顧客への対応を意味するなら、「新規顧客への対応手順を変更する案」と書く。

修飾語は修飾先が分かる位置に置く。「担当者が昨日提出した報告書」なら、昨日提出されたのが報告書だと分かる。読点は係り受けや語の切れ目を示せるが、文の構造が定まらないまま読点だけを増やしても解決しない。

## 話題と焦点をつなぐ

「は」は話題を設定し、対比にも用いる。「が」は述語に対する主語を示すほか、誰が行ったのかという焦点を表すことがある。

> 担当者は確認した。管理者はまだ確認していない。

> 誰が確認したのか。担当者が確認した。

同じ人物と動作でも、前者は人物を対比し、後者は問いの答えを示している。助詞を表記の揺れとして統一しない。

主題や主体が文脈から明らかな場合は省略できる。「担当者は資料を受け取り、内容を確認した」は、同じ担当者の動作として読める。途中で管理者へ動作が移るなら、その主体を示す。

「この結果」「それ」は、読者が指す対象を定められるところで使う。複数の結果が並んだ後では、必要な名詞を繰り返す方が短い指示語より負担が小さい。段落を変えるだけで、前段の条件や対象が解除されるわけではない。

## 出来事のどこを中心にするか

能動は動作主を、受身は動作を受ける側を中心に述べる。

> 委員会が申請を承認した。

> 申請は委員会に承認された。

前者は委員会の行為を説明し、後者は申請の扱いを説明している。判断の責任を伝えるなら動作主を明らかにする。対象の状態を続けて説明するなら、受身が適する場合がある。受身には「雨に降られた」のように影響を受けた側を述べる用法もあり、すべてが能動文の単純な置換ではない。

使役は、他者に動作をさせる関係を表す。「管理者が担当者に再実行させる」では、働き掛ける人と実行する人が異なる。使役には強制にも許容にも読めるものがある。権限や責任の違いを伝える場合は、「再実行を命じる」「再実行を許可する」のように必要な関係を直接表す。

## 時間と状態を表す

時制は出来事を時間上に位置付ける。アスペクトは、出来事を進行中や完了後の状態などとして捉える働きである。

| 表現 | この文脈で伝えること |
| --- | --- |
| 今、担当者がファイルを更新している | 更新作業が進行中である |
| ファイルは更新済みである | 更新が完了している |
| 扉が開いている | 開いた後の状態が続いている |

「ている」は進行だけを表すとは限らない。「た」も過去のほか、「こんな所にあった」のように発見を表すことがある。形だけで状態を決めず、動詞と文脈に合う表現を選ぶ。

報告では時間の基準を示す。「現在」が観測時点なのか読者が読む時点なのかで、成立する内容が変わることがある。また、「確認してから送る」と「送ってから確認する」は別の手順である。語順の整理で出来事の順序を変えない。

## 否定と限定の範囲を保つ

否定は、何が成立しないかを表す。数量や条件と組み合わさると、否定する範囲が重要になる。

> すべての申請を承認したわけではない。

> どの申請も承認しなかった。

前者は全件承認を否定しており、一部を承認した場合を含む。後者は承認が一件もないことを述べる。「必ず成功するわけではない」も、「必ず失敗する」とは異なる。

「だけ」「しか」は対象を限定する。標準的な「しか」は否定形と組み合わせる。「管理者しか変更できない」は、管理者以外では変更できないことを表す。限定語の位置にも意味がある。「管理者だけが設定を変える」は主体を限定し、「管理者が設定だけを変える」は対象を限定する。

「も」は同類の追加に使い、数量に付くと「百人も来た」のように多さを表すこともある。形式を付けるだけで、追加や意外さの基準が読者に伝わるわけではない。必要な比較の文脈と結び付ける。

二重否定は解釈の手間を増やす一方、留保や限定を表す場合がある。「対応できないわけではない」を「対応できる」とすると、その含みを失い得る。単純な肯定で同じ意味になる場合に言い換える。

## 確かさと働き掛けを区別する

モダリティは、内容に対する書き手の判断や、読者への働き掛けを表す。内容が何かに加え、どの確かさや拘束力で述べるのかを選ぶ。

| 伝える意味 | 表現例 |
| --- | --- |
| 発生を確言として述べる | 接続が切れた |
| 発生の可能性を述べる | 接続が切れたかもしれない |
| 行為を義務付ける | 提出しなければならない |
| 行為を許可する | 提出してよい |
| 行為を禁止する | 提出してはならない |
| 義務がないと述べる | 提出する必要はない |

確言の形で書いたことは、内容が真である証拠にはならない。分かっていることに合わせて確かさを表す。条件が分かったことと、その条件下で必ず起こることも別である。推量を削って断定したり、根拠のない慎重さを加えたりしない。

「できる」は能力や実現可能性にも使われるため、許可を伝える場面では「してよい」などで区別する。「べきだ」は規範的判断や推奨として使われるが、文書で義務表現が定義されていればその定義に従う。一般語の印象で要求の強さを変えない。

## 節と文の関係を表す

接続は、二つの内容がどのようにつながるかを示す。原因なら「ので」「から」、目的なら「ために」、譲歩なら「ても」など、必要な関係を表す形式を使う。「再試行しても失敗する」と「再試行したので失敗する」では、再試行と失敗の関係が異なる。

条件の「と」「ば」「たら」「なら」は、意味が重なる場面もあるが、常に交換できるわけではない。

> 参加するなら、連絡してほしい。

> 参加したら、連絡してほしい。

前者は参加を前提に連絡を求める。後者は参加後の連絡と読まれ得る。前件が仮定か既成の事実か、後件が依頼か結果の説明かによっても適する形式が変わる。

並列では項目の共通の受け先を示す。「AとBを提出する」と「AまたはBを提出する」では、両方が必要か選択できるかが違う。両方を選べるかが判断に関わる場合は、その扱いを明示する。単なる出来事の連続を「だから」で結び、因果関係を作らない。

## 相手と場面に合う言葉遣い

敬語は、誰の行為を述べ、誰に向けて話すかに関わる。「おっしゃる」は行為者を立てる尊敬語である。「申し上げる」は自分側の発言が向かう先を立てる謙譲語であり、単に文末を丁寧にする働きとは異なる。

相手との親疎や場面の改まりに合わせて、丁寧さを選ぶ。文体の選択と敬語の誤用を混同しない。「です・ます」と「だ・である」のどちらかが文法的に優れるわけではない。体言止めも見出しや要約に使えるが、説明文で判断や動作まで省くと、読者に述語を補わせることになる。
