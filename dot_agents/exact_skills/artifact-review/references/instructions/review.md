# 指示レビュー

スキル本文、システムプロンプト、AGENTS.md その他の指示文について、想定する実行者が指示を受け取る実際の文脈で、その動作を実行できるかを検査する。

指示文は自然言語であるため、文書レビューも適用する。

検査観点が指定されていない場合はすべての観点を検査対象にする。

## 実行者文脈

想定する実行者が指示の発動時点で実際に利用できる入力、状態、権限、参照先を、検査対象と判断根拠となる正本から確認する。

レビューのために与えられた情報は指示の正しさを照合するために使う。
実際の実行時にも実行者へ渡ることを確認できる情報だけを、実行者が利用できる文脈として扱う。

## 検査方法

想定する実行者として、指示が発動してから結果を返すまでの経路をドライランする。
各時点で実行者が実際に持つ入力、状態、権限だけを使い、次に行う動作を決められるかを確認する。

条件が変わる境界、必要な入力を得られない場合、操作が失敗する場合についても経路を追い、指示された停止や返却まで実行可能であることを確認する。

他の指示や成果物と接続する場合は、その接続先を直接確認し、必要な情報と責務が実際に接続することを確認する。

問題の候補を見つけた場合は、実行者がどの時点で何を知っており、どの指示を適用した結果、どの動作を決められないか、または誤った動作へ進むかを実行者文脈から再現する。
