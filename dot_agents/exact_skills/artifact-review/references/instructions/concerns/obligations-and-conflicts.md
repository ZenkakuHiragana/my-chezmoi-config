# 行動と判断の明確さ

レビュー担当者は、有効な指示を同じ実行状態へ適用し、実行者が必要な判断と動作を決められるかを確認する。

- 行動要求について、実行する主体、対象、条件、順序が分かるか。条件を判断する主体と動作を行う主体が異なる場合、その分担を読み取れるか。
- 必須、禁止、推奨、許可、任意を読み分けられるか。抽象的な希望や曖昧な語が、必要な判断条件の代わりになっていないか。
- 同じ状態で成立する規則が、同じ対象に両立しない動作を要求しないか。例外と優先順位を適用した後にも衝突が残らないか。
- 対象の利用場面で遭遇する状態について、必要な動作を決める規則が欠けていないか。条件の境界、状態の変化、通常と異なる入力にも、適用すべき規則を決められるか。
- 用語、指示語、状態名が一貫した意味で使われ、複数の解釈が異なる義務や結果を生まないか。必要な前提と処理結果の順序が逆転していないか。
- 実行者に許された裁量の範囲と、守るべき結果・制約を区別できるか。複数の行動が許されていることと、必要な判断が未定義であることを区別できるか。

レビュー担当者は、正当な裁量まで単一の動作へ固定することを求めない。曖昧さや矛盾を指摘する場合は、成立する状態、適用される記述、結果を変える解釈または両立しない動作を示す。説明に行動要求がないことは、この観点の欠陥にしない。
