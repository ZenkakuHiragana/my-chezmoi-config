# 実行文脈

レビュー担当者は、各動作が必要とする情報・能力と、その時点で実行者に与えられる入力、道具、権限、実行環境、資源を照合する。

- 必須入力と参照先に、実行者が実際に到達して読み取れるか。入力の所有先、対象範囲、必要な版や読み取り条件を確認でき、別の対象や古い状態を使わずに済むか。
- 指示された操作を、実行者の道具と能力で実行できるか。時間・容量・費用に適用される制約がある場合、その範囲内で操作と必要な確認を行えるか。
- 読み取り、変更、外部公開、資格情報の利用に必要な権限を区別しているか。操作の副作用も含めて、実行者の権限と対象範囲を越えないか。
- 許可された操作と禁止された操作の境界が、代替手段にも維持されるか。拒否や失敗の後に、禁止された副作用を別経路で実現するよう誘導していないか。
- 入力不足、到達不能、読み取り専用、権限不足の状態でも、実行者が情報や成功を捏造せず、定められた停止・返却へ進めるか。

レビュー担当者は、レビュー用の資料や別の主体の知識を、実行者が利用できる入力として補わない。利用不能な入力・能力を特定するのはこの観点で行い、その後の終了・回復経路は「終了と回復」で確認する。
