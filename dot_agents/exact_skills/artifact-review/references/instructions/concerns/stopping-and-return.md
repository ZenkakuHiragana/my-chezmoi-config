# 終了と回復

レビュー担当者は、指示の利用場面に含まれる成功、失敗、入力不足、権限不足、到達不能、拒否、中断の経路を、終了・返却・回復までたどる。

- 実行者が、どの状態で作業を終え、何を誰へ返し、何を返してはならないかを判断できるか。成功と未達成を区別し、未確認を成功として返したり失敗を黙って飲み込んだりしないか。
- 再試行する場合、何が変われば進展し、何をもって再試行をやめるかを判断できるか。縮小、取り消し、別の判断者への返却も含め、同じ状態へ戻り続ける経路がないか。
- 回復を担当する主体が、回復に必要な情報と権限を持つか。回復できない場合に、その主体が未解決事項を扱える相手へ返せるか。
- 中断や失敗までに変更が一部実行される場合、残った状態と副作用を確認できるか。取り消しや再開を要求する指示では、その対象と実行条件が分かるか。
- 常時稼働する指示では、継続すべき条件と、中断・終了要求への応答が分かるか。完了する仕事の反復と、目的上必要な継続を区別できるか。

レビュー担当者は、終了しないことが用途上正当な指示に有限終了を一律に要求しない。回復や取り消しが必要かは対象の要求と副作用から判断し、すべての指示に新たな回復機構や回数制限を要求しない。
