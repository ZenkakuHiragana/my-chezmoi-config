# 接続と責務

レビュー担当者は、呼び出し側、実行者、委譲先、結果の利用者が接する指示や成果物を直接読み、接続の両側で期待する意味と責務を照合する。

- 誰が何を生成し、誰へ渡し、受け手が何に使うかを確認できるか。入力・出力の内容、形式、対象範囲、引き渡し条件が両側で一致するか。
- 実行者自身が決める範囲と、接続先や別の判断者へ渡す範囲が分かれるか。必要な判断を双方が相手任せにしたり、双方が独立に確定したりしないか。
- 入力・出力・状態・永続化について、所有先と更新の担当が一貫しているか。引き渡し時点の状態を双方が異なる意味で扱わないか。
- 同じ責務が重複し、競合する動作を生んでいないか。必要な責務がどの主体にも割り当てられず、実行経路から抜けていないか。
- 接続先が返す成功、失敗、未確定を、受け手が区別して次の判断に使えるか。部分的な結果や未解決事項が受け渡しの途中で失われないか。

レビュー担当者は、接続の存在や参照名の一致だけで成立とせず、情報と責務が実際に受け渡される経路を確認する。終了後に何を返すかは「終了と回復」と照合し、返された内容を利用側が解釈できるかをこの観点で扱う。
