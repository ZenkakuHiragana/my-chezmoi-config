# 目的と結果

レビュー担当者は、依頼・要件・仕様に示された目的と利用場面を、文書の説明、要求する行動、返す結果に照合する。要求の必要性、正確性、集合としての完全性を、次の対応から確認する。

- 目的の達成に必要な結果が、指示された行動と出力によって得られるか。通常の経路だけでなく、対象の利用場面に含まれる境界条件でも必要な結果が抜けていないか。
- 各義務・禁止・条件が何の要求を支えるか。必要な要求から指示への欠落と、指示から根拠への接続がない余分な要求を、両方向から確認できるか。
- 指示に忠実に従っても、手続きや中間成果の完成だけで終わり、必要な結果を得られない経路がないか。
- 行動から結果が得られるという説明に、未確認の前提や外部の協力への依存が隠れていないか。その前提が想定する利用環境で成立するか。
- 指示が目的を狭めたり別の目的へ置き換えたりしていないか。説明や案内は、その用途に必要な理解と参照を支えているか。

レビュー担当者は、要求する結果の妥当性をここで扱い、その結果を測れるかは「確認可能性」で扱う。目的や根拠を確認できない場合は、望ましい目的を補わず判断できない点を返す。要求仕様に対する実装方法の独立性をそのまま指示へ適用せず、手順を指定していること自体を欠陥にしない。
