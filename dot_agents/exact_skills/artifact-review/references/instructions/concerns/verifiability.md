# 確認可能性

レビュー担当者は、要求する結果と、その結果の成否を区別する観測方法・証拠・判定条件を照合する。

- 各結果を、対象の事実、実行結果、引用、差分、テストから確認できるか。必要な証拠を誰がどの時点で取得し、誰が判定に使うかが分かるか。
- 観測方法が、その要求を満たす場合と満たさない場合を区別できるか。作業の実施や自己申告だけを、要求した結果の成立の証拠にしていないか。
- 要求する結果に対応する検査が欠けていないか。逆に、検査が失敗したという理由だけで、要求にない新しい合格条件を加えていないか。
- 証拠の対象、時点、条件、範囲が、判定する結果と対応するか。測りやすい別の結果や一部の成功を、目的とする結果全体の達成に置き換えていないか。
- 未実施、確認不能、不合格を区別し、確認結果の意味、限界、未実施の理由を利用者へ返せるか。

レビュー担当者は、要求した結果が目的に適するかを「目的と結果」で扱い、その成否を確かめられるかをこの観点で扱う。検査手順の記載があることと、実際に証拠が得られたことを区別し、実施していない検証を成功扱いしない。
