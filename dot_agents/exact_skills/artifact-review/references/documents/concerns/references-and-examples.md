# 参照と記載例

読者に別の資料の参照や、コード・手順の利用を案内する文書に適用する。
案内に従って、説明された情報や結果を得られるかを確認する。

## 参照先を確認する

リンクや参照の記述から、何を得るためにどこへ進むのかを確認する。
構文だけでなく、想定読者が通常の利用経路で到達でき、案内された情報を得られるかを調べる。
参照先の対象や版が、本文の説明と対応しているかも確かめる。

レビュー担当が閲覧できることだけを、読者も到達できる根拠にしない。
逆に、レビュー担当が確認できないことだけで、読者にも到達不能だと断定しない。

## 記載例を確認する

実行や操作を案内する例では、本文が示す環境と前提を確認する。
読者が指定する値と、そのまま使う文字列を区別できるかを確かめる。
説明用の断片を、完成した実行手順と取り違えない。

記載例の実行結果を確認する必要があり、その操作が認可されている場合は、記載どおりに実行して説明された結果になるかを確認する。
権限や環境がなく実行できない場合は、照合できた内容と未実施の確認を分けて報告する。
実行していないことを、例の失敗や成功として扱わない。

指摘には、問題となる参照または操作、その成立条件、説明と異なる結果を示す。
