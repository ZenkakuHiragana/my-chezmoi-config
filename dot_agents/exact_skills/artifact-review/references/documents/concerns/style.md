# 文体

語彙や表記が、読者と利用場面に合い、伝えるべき意味を自然に表しているかを確認する。
概念の取り違えや、不要な言い換えによる読みにくさなど、対象の文章で起きている問題を確かめる。
自然に読めても正本と意味が違う場合は、意味の不一致として扱う。

## 読者に合う語彙

使われている語が、説明する概念を正確に指しているかを確認する。
読者が直接理解できる定着した日本語があるのに、一般語を外国語表記にしたり、意味の定まらない呼び方を持ち込んだりしていないかを調べる。
外国語由来であっても、定着したカタカナ表記があるものや対応する日本語語彙があるものは定着した日本語である。

識別や操作に必要な原表記は、正確に保たれているかを確かめる。
正式名称や設定名、ドメイン固有の用語、コード中の識別子などを、日本語へ置き換えたため対象を特定できなくしていないかを調べる。
略称や専門語については、読者がその意味を知っているか、必要な説明を本文から得られるかを確認する。

同じ概念には同じ呼び方を使い、異なる概念は区別できるかを確かめる。
指定された用語や表記規則がある場合は、その適用範囲と実際の記述を照合する。
表記揺れを指摘するときは、異なる表記の出現箇所と、それらが同じ概念を指す根拠を示す。
名称の一部に同じ語が含まれるだけで、別の概念を一つにまとめない。

何を指すかを確認できない場合は、統一する呼び方を推測で決めない。
意味の違いが説明全体の関係を変えている場合は、構成の観点とも照合する。

## 文体と相手との関係

文末や呼び掛けが、文章の用途と、書き手と読者の関係に合っているかを確認する。
敬語では、誰の行為を誰に対して述べているかを確かめる。
丁寧に見せるための表現が、行為者や相手を取り違えるものになっていないかを調べる。

同じ立場から続く説明では、文体の変化によって話者や要求の強さが変わって読めないかを確認する。
引用や会話では、主体が変われば文体も変わり得る。
複数の文体があることだけで統一を求めず、それぞれが誰の言葉かを読者が区別できるかを確かめる。

推量表現は、不確実性を伝えるために必要かを確認する。
未確認の内容を断定へ変えたり、確かな内容を曖昧にして責任や結論を分からなくしたりしていないかを、根拠と照合する。
表現を整えることと、主張の確かさを変えることを区別する。

## 補足と反復

括弧や注記が、その位置で本文の理解を助けているかを確認する。
用語の別名や短い補足は役に立つ場合がある。
一方、見出しや本文を言い直すだけの補足が続き、読むたびに主題から離れなければならない箇所を調べる。
判断に不可欠な条件を、付け足しのように扱って見落とさせていないかも確かめる。

説明の反復は、それぞれの位置で必要な役割を持つかを確認する。
独立した節の前提や安全条件の再確認を、同じ内容があるという理由だけで不要にしない。
同じ主張を言い換えるだけで説明が進まない場合や、言い換えによって別の条件に見える場合は、その箇所を示す。

「としては」「については」のような表現が、必要な対比や話題の限定を示しているかを確認する。
「など」「等」も、例示として使われているのか、特定すべき対象を曖昧にしているのかを区別する。
語の有無だけで削除を求めず、その表現が担う意味を確かめる。

書き手の都合や編集経緯を述べる前置きは、読者が文書を使うために必要かを調べる。
「この文書では簡潔にまとめる」のように、扱う内容を示さず進行を遅らせるだけの記述がないかを確認する。
適用範囲を伝えることで読者の選択を助けている場合は、その役割を認める。

## 句読点と空白

句読点や空白によって、語のまとまりと文の区切りを読み取れるかを確認する。
読点の数や一文の長さだけで適否を決めない。
表記規則が指定されている場合は、その規則が対象とする文章や媒体を確かめて照合する。

日本語の語と語の間に空白がある場合は、区切りとして必要なのか、語のまとまりを誤認させているのかを調べる。
日本語と英数字や記号の境界に空白があること自体は問題にしない。
コードやコマンドでは空白が固定文字列の一部になり得るため、散文の表記規則を機械的に当てはめない。

## 強調と表示

強調が、読み落とすと理解や行動が変わる箇所を見つける助けになっているかを確認する。
強調する範囲が不明確だったり、多用によって重要度を区別できなくなったりしていないかを調べる。

Markdown の太字と斜体には、ここで採用する表記方針を照合する。
強調構文の外側に日本語の文字が接する箇所は、半角スペースで区切られているかを確認する。
強調部分の末尾に日本語の句読点が続く場合は、その句読点を強調の内側に含めた形になっているかを確かめる。

この方針に合う例:

- 文章中の **強調** 構文。
- これは **句点を含む。** 次の文の前に半角スペース。
- 英単語 _emphasize_ は強調するという意味。

日本語の斜体は、想定する表示環境で機能することを確認できるかを調べる。
確認できない環境で使われている場合は、この表記方針への不適合として扱う。

表記方針への適合と、実際の表示の成否は分けて確認する。
強調記号が文字として残る、内容が欠ける、意図しない範囲が強調されるといった表示失敗は、対象の表示環境か最終生成物で確かめる。
表示できていても表記方針に反する場合は、表示失敗とは区別して示す。
CommonMark の仕様だけを、対象環境で正常に表示された根拠にしない。

## 外部資料

語彙や文体を資料に照合するときは、読者と文章の種類に適用できる範囲を確認する。
特定分野の表記規則を、日本語一般の正誤へ広げない。

- [文化庁「分かり合うための言語コミュニケーション」](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/wakariau/pdf/r1403493_01.pdf): 正確さ、分かりやすさ、場面へのふさわしさ、敬意と親しさの関係を確認する。
- [文化庁「敬語の指針」](https://www.bunka.go.jp/seisaku/bunkashingikai/sokai/sokai_6/pdf/keigo_tousin.pdf): 敬語が誰の行為と関係を表すかを確認する。
- [国立国語研究所「『外来語』言い換え提案 利用の手引き」](https://www2.ninjal.ac.jp/gairaigo/Teian1_4/tebiki.html): 文脈に応じた言い換え、説明、原語保持の判断を確認する。
- [日本翻訳連盟「JTF日本語標準スタイルガイド（翻訳用）」](https://www.jtf.jp/tips/styleguide): 実務翻訳での表記統一を確認する。対象が採用していない規則を、日本語一般や Markdown の仕様として強制しない。
- [国立国語研究所「日本語の文章で読点のルールはどうなっていますか」](https://kotoba.ninjal.ac.jp/qa/yokuaru/qa-53/): 読点の働きと、文脈による判断の幅を確認する。
