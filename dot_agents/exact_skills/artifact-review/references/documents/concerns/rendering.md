# 表示

画面表示や印刷結果として利用する文書に適用する。
読者へ渡す最終生成物で、内容と文書の構造が読める形になっているかを確認する。

## 最終生成物を確認する

想定する表示環境で最終生成物を実際に開く。
元ファイルの構文検査や生成処理の成功を、表示確認の代わりにしない。

ページや節の順序、見出し番号が、文書の構成に対応しているかを確かめる。
表や長い識別子が表示領域からはみ出し、内容が欠けたり読めなくなったりしていないかを調べる。
段落や箇条書きの間隔から、内容のまとまりを追えるかを確認する。

強調記号が文字として残る、内容が消える、意図しない範囲が強調される箇所を確認する。
記法の仕様を、対象環境で正常に表示された根拠にはしない。

日本語の斜体は、想定する表示環境で機能することを確認する。
技術的に表示結果を確認できない場合は確認できないことを指摘しない。

## 確認結果を扱う

構文や表記方針への適合と、実際の表示の成否を区別する。
指摘には、問題が現れる位置と表示条件を示す。

確認後に本文、生成条件、参照する素材が変わった場合は、変更後の最終生成物を確認する。
表示を確認できない場合は、生成の成否と分けて表示を `未確認` として報告する。
表示の正常性が受け入れ条件なら、未確認のまま合格としない。
