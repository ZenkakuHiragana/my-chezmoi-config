# 日本語文書レビュー

日本語の文書、コメント、説明、プロンプト、スキル本文、利用者向けメッセージについて、その文書を実際に読む読者の理解と利用を検査する。

検査観点が指定されていない場合はすべての観点を検査対象にする。

## 読者文脈

文書を読む主体と、その文書が通常どのように利用されるかを、検査対象と判断根拠となる正本から確認する。読者に依存する判断に必要な情報を確定できない場合は、その判断を推測で行わない。

読者の文脈は、読者が成果物を受け取った時点で安全に持っている知識と、本文を利用する過程で得られる情報から構成する。本文から参照され、その読者が通常の利用経路で実際に到達できる資料は読者文脈に加えてよい。

レビューのために与えられた正本は、本文の記述が正しいかを照合するために使う。読者自身もその情報へ到達できる場合に限り、その内容を読者が知っているものとして扱う。

## 検査方法

想定する読者として、その文書の主な利用を一度ドライランする。読者が実際に使う入口から本文を読み、検索し、参照を辿り、その時点までに得られた情報だけを使って必要な理解または判断へ到達できるかを確認する。

文章の途中で用語、指示対象、条件、理由、参照先などを解釈するときは、読者がその位置までに得ている情報から意味を回復できるかを確認する。後から現れる説明や、書き手だけが持っている作業文脈を先取りして補わない。

問題の候補を見つけた場合は、前後の文章と読者から到達できる参照先を使って再読し、実際の読者文脈でその問題が成立することを確認する。

対比、否定、注意書きなどがある場合は、それが読者の文脈に実際に存在する解釈へ応答しているかを確認する。否定または対比されている解釈を、そこまでの本文、読者から到達できる資料、またはその読者が安全に持つと確認できる知識のいずれからも導けない場合、その文章は読者に新しい前提を持ち込んでから否定している。これは読者の理解を損なう構成上の問題として扱う。
