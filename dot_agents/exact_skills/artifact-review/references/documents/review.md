# 文書レビュー

読者へ渡す文書または生成物について、検査の前提と適用する観点を確認する。

## 検査の前提を確定する

依頼と判断根拠となる正本から、何を伝える文書で、誰がどの場面で利用するかを確認する。
元になる情報と照合する場合は、文書が扱う対象と時点に合う正本を使う。

読者が持つ知識と、通常の利用経路で得られる情報を、レビュー担当だけに与えられた資料と区別する。
正しさの照合に使う資料を、読者も既に知っているものとして扱わない。
参照先へ到達できることと、その内容を読む前から理解していることも区別する。

必要な前提を確認できない場合は、そのために判定できない範囲と不足している情報を示す。
特定の読者や意図を推測で補って、適否を確定しない。

## 適用する観点

検査観点が指定されている場合は、その検査に必要な観点資料を使う。
指定されていない場合は、以下の観点資料をすべて読み、それぞれの適用条件に従って検査する。

- 構成: `concerns/structure.md`
- 文法: `concerns/grammar.md`
- 文体: `concerns/style.md`
- 誤記: `concerns/typo.md`
- 読解負荷: `concerns/reading-load.md`
- 表示: `concerns/rendering.md`
- 参照と記載例: `concerns/references-and-examples.md`

検査方法と指摘の条件は、担当する観点の記載に従う。
日本語に固有の基準は、日本語の箇所に適用する。
