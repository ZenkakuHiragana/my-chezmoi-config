# Python レビュー用プロファイル

Python の値の比較、共有状態、例外処理によって、表面上の式からは分かりにくい挙動が生じないかを確認する。
対象が使うライブラリーや実行環境の仕様も照合し、見た目の簡潔さだけで実装を判断しない。

## 実行環境と公開する契約

使用する Python と依存先の版を確認し、実際に読み込まれるモジュールを調べる。
公開する名前やインポート先が、説明と実装で一致するかを確かめる。
配布するパッケージでは、ソースの作業ディレクトリにあるファイルを偶然読み込んで成功していないかも見る。

検査には、対象に設定されたテストや型検査、静的解析を使う。
型注釈や検査の成功だけで、外部から得た値の実行時検証まで済んでいるとは判断しない。
利用者へ示す例外や警告、設定の説明も、対象の版の動作へ照合する。

## 比較とキャッシュの意味

`is` による同一性と `==` による等価性を区別し、その比較で何を同じものとして扱うかを確認する。
キャッシュや重複除去では、等しい別オブジェクトと、同じオブジェクトを渡す場合を分けて調べる。
文字列化や並べ替えへ置き換えたことで、必要な区別を失っていないかも確かめる。

比較する値の型を調べ、`__eq__` や真偽値判定で実行される処理を確認する。
等価比較の結果が単純な bool でない場合や、比較が例外を投げる場合には、その結果を使う条件式までたどる。
同一性で比較を省く処理も含め、実際に要求される等価性と一致するかを見る。

辞書や集合のキーでは、等しいキーが同じハッシュ値を持つかを確認する。
格納後に比較やハッシュ化へ使う値が変わり、検索できなくならないかも調べる。
比較やハッシュ化の費用も、値の大きさと実行回数に照らす。
正しい結果を返すことだけで性能上の問題を見落とさない。

既存のコメントやコードに、高価な比較や変換を避ける理由がある場合は、その理由を現在の利用条件で確かめる。
変更のレビューでは、処理を別の場所へ移しただけで同じ費用が復活していないかを調べる。
以前の説明を無条件に正しいとはせず、影響の有無は実装と入力から判断する。

## 共有する値と遅れて実行する処理

変更可能な既定引数やクラス属性は、どの呼び出しやインスタンスが同じ値を共有するかを確認する。
代入や浅いコピーによって、入れ子の値だけ共有が残る場合も調べる。
初期化用の値を作ったつもりで、別の利用者の状態を更新していないかを見る。

クロージャーは、作成時の値と、呼び出す時点で参照する変数を区別する。
ループ内で作ったコールバックが、すべて同じ後の値を使わないかを確かめる。
イテレーターやジェネレーターも、使う時点と消費する回数を調べ、一度読み終えた結果を再利用できる前提になっていないかを見る。

## 正規表現による検証

検証する範囲が文字列全体なのか、一部の一致で足りるのかを確認する。
`$` は末尾の改行の直前にも一致し得るため、全体を拒否・許可する検査に使う場合は、その違いを確かめる。
`MULTILINE` の有無と、使用する照合関数も合わせて確認する。

空文字列や末尾改行、許可する文字の境界を、対象の入力仕様へ照合する。
文字列とバイト列で扱えるパターンや文字の解釈が異なる箇所も調べる。
全体一致を必要としない検索へ、一律に `fullmatch` を要求しない。

## 例外と後始末

成功した場合だけでなく、捕捉する例外、捕捉しない例外、ハンドラーがない場合からも、必要な後始末までたどる。
例外処理の途中で別の例外が起きる場合や、利用者のコールバックが失敗する場合も、失われる処理と状態を確認する。

`finally` やコンテキストマネージャーでは、元の例外を隠していないかを調べる。
`finally` 内の `return` や `__exit__` の戻り値が、伝えるべき失敗を消していないかを確認する。
フレームワークが管理する後始末も、フックの名前だけで判断せず、セッションの保存や状態の復元へ至る実際の呼び出し順を確認する。

pytest の `yield` を使うフィクスチャーでは、`yield` へ到達する前の失敗を確認する。
そのフィクスチャーの `yield` 後の処理が実行されない場合にも、取得済みの資源を後始末できるかを調べる。
フィクスチャーの共有範囲によって、別のテストへ状態が残らないかも確かめる。

非同期処理では、キャンセルを受けた後の後始末と、その結果を待つ側への伝達を確認する。
キャンセルを捕捉して無視することで、呼び出し側やタスク管理の仕組みが想定する終了を妨げていないかを見る。

問題を指摘するときは、比較する値の性質や失敗の起きる位置を示す。
抜粋だけでは分からない初期化や終了処理を推測で補わず、確認できた不具合と不足する文脈を分けて返す。
