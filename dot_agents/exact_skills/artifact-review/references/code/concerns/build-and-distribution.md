# ビルドと配布レビュー

ビルド、生成、パッケージ、配布、配置の経路が変更または成果物の利用結果に影響する場合に使う。コードの実行時の正しさや外部契約そのものは、それぞれの観点で確認する。

## きっかけ

- コンパイル、型検査、静的検査、生成、パッケージ、起動、配布、配置の各経路に変更がある。
- ビルド設定、環境変数、機能切り替え、資源ファイル、移行処理に変更がある。
- CMake、Cargo、CI 設定、YAML、JSON、SQL、スキーマ、マイグレーション、環境変数がビルドまたは配布結果を決める。

## 質問

- 変更したソースがビルドに含まれるか。生成物が古いままにならないか。
- 開発時だけ成功し、清潔な環境、別の構成、継続的な確認、実配布物で失敗しないか。
- 対象となる設定やデータの型、既定値、引用、順序、版、生成物、清潔な環境での再現性は確認できるか。
- 構文が通ることだけで、意味の正しさを認めていないか。
